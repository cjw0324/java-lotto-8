# java-lotto-precourse

우아한테크코스 프리코스 3주차 과제 “로또” 요구사항 정리 문서입니다.  
간단한 로또 발매기를 구현한다.

---

## 프로그램 개요

- 입력:
    - 로또 구입 금액 (1,000원 단위)
    - 당첨 번호를 입력 받는다. 번호는 쉼표(,) 기준 구분
    - 보너스 번호
- 처리:
    - 차수별 실행 결과
      - 우승자 안내 문구
- 출력:
    - 발행한 로또 수량 및 번호를 출력, 로또 번호는 오름차순 정렬하여 보여준다 :
    ~~~
    8개를 구매했습니다.
    [8, 21, 23, 41, 42, 43]
    [3, 5, 11, 16, 32, 38]
    [7, 11, 16, 35, 36, 44]
    [1, 8, 11, 31, 41, 42]
    [13, 14, 16, 38, 42, 45]
    [7, 11, 30, 40, 42, 43]
    [2, 13, 22, 32, 38, 45]
    [1, 3, 5, 14, 22, 45]
    ~~~


  - 당첨 내역을 출력한다 :
    ~~~
    3개 일치 (5,000원) - 1개
    4개 일치 (50,000원) - 0개
    5개 일치 (1,500,000원) - 0개
    5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
    6개 일치 (2,000,000,000원) - 0개
    ~~~
  - 수익률은 소수점 둘째 자리에서 반올림하여 출력한다 : 
    ~~~
    총 수익률은 62.5%입니다.
    ~~~
    

- 예외: 잘못된 입력 시 에러 문구를 출력해야 한다
    ~~~
    [ERROR] 로또 번호는 1부터 45 사이의 숫자여야 합니다.
    ~~~

## 도메인 분리

- 사용자 (User)
  - lottos : 보유한 로또들
  - purchaseAmount : 구입 금액
  - totalEarnings : 총 당첨금
  - yield : 수익률

- 로또 (Lotto)
  - 6개의 중복되지 않는 번호 집합을 가진 객체
  - 스스로 유효성 검증
  - 내부적으로 List<Integer> 보관 (주어진 numbers)
  - 역할 : 
    - 불변 객체로 관리
    - 비교 로직을 제공

- 로또 발매기 (LottoGenerator)
  - 로또를 발행하는 책임
  - 1~45 범위의 숫자 중 6개를 무작위로 선택해 Lotto 객체를 생성
  - 구입 금액에 따라 여러 장 발행
  - 역할 : 
    - 로또를 생성
    - 입출력과 분리

- 로또 추첨기 (WinningLotto)
  - 입력 받은 숫자들을 객체로 변환
    - 6개 당첨 번호
    - 보너스 번호 1개

- 로또 등수 계산기 (LottoScoreCalc)
  - 구매한 모든 로또와 당첨 번호를 비교하여 결과를 계산

- 로또 판매자 (LottoSeller)
  - 사용자의 금액에 해당하는 로또를 판매하는 행위를 담당
  - 사용자에게 로또 개수만큼 랜덤 로또를 추가해줌

- Controller
    - 프로그램의 흐름을 제어
    - View 와 도메인 객체간 의존 관계 연결

- 입력
- 출력
- 예외 메시지
- 검증
  - 입력 받은 문자열 검증
  - 입력 받은 금액 검증

## 구현할 기능 목록 (Commit 단위)

- Controller 추가

- User 구현
  - User 생성 시 구입 금액 검증 (1,000원 단위)
  - User가 구입 금액만큼 로또 구매
  - User가 당첨 결과 및 수익률 계산

- 로또 발매기
  - 1~45 범위의 중복되지 않는 6개 숫자 생성
  - 구입 금액에 따라 로또 여러 장 생성
  - 발행된 로또 번호를 오름차순으로 정렬

- 로또 추첨기
  - 당첨 번호 입력받아 생성 (중복 검증)
  - 보너스 번호 검증 (당첨 번호와 중복 불가)
  - 당첨 번호, 보너스 번호 저장 및 조회

- 로또 등수 계산기
  - 로또 1장과 당첨 번호 비교 (일치 개수 + 보너스 여부)
  - 등수 판단
  - 여러 로또 결과 집계
  - 총 수익률 계산

- 입출력
  - 구입 금액 입력받기
  - 당첨 번호 및 보너스 번호 입력받기
  - 구매한 로또 목록 출력
  - 당첨 내역 및 수익률 출력
  - 예외 발생 시 `[ERROR]`로 시작하는 메시지 출력 후 재입력

- 검증
  - 금액이 1,000원 단위인지 검증
  - 로또 번호가 1~45 범위인지 검증
  - 로또 번호 중복 여부 검증
  - 당첨 번호와 보너스 번호 중복 검증
